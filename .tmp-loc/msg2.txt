Two pieces of duplication went the other way while I was in here:

  - The five packages that own a namespace each had the same twenty-line
    layering hook copied out. That is now `createBundleTranslation(BUNDLE)` in
    @duncit/app-settings, and each package's module is three lines over it. The
    layering itself is the subtle part and is documented there once: inside a
    LocaleProvider the shared hook returns the PROVIDER's translator and ignores
    the fallback handed to it, so a package whose namespace the host never
    mounted would render raw keys.
  - `portals/onboarding` kept a hand-copy of @duncit/media-picker's media list
    field. The package's version had gained the AI Monitoring notice every
    upload field is supposed to carry and the copy had not — which is the drift
    rule 40 exists to stop. The copy is deleted and the console re-exports the
    package's; its now-unused `onboarding.mediaListField.*` rows go with it.

The websites' build-time translator moved into @duncit/brand
(`@duncit/brand/site-i18n`) so all four marketing sites share one implementation

(70 -> 165), and that is deliberate. `mwebHostPodLabels` and

that file goes down; the repo total falls from 10578 to 10357 lines.
